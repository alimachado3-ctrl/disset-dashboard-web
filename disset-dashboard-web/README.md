# Disset Dashboard Web

## Variables (en Vercel)
- `NEXT_PUBLIC_SUPABASE_URL` = Project URL (Supabase → Settings → API)
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` = anon key (Supabase → Settings → API)
- `SUPABASE_SERVICE_ROLE` = service_role key (solo server)

## Deploy
1. Subí este repo a GitHub.
2. En Vercel: New Project → importá el repo → agregá las variables → Deploy.
